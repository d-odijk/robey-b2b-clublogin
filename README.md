# Robey B2B: clublogin (prototype)

Ontwerpprototype van de clublogin in de Robey B2B-portal (fase 2). Geen werkende winkel: bestellen,
inloggen en de checkout zijn nagebootst, prijzen en voorraad zijn voorbeelden.

Bekijken: https://d-odijk.github.io/robey-b2b-clublogin/

Het bestand wordt gemaakt door `bouw-club.py` en niet met de hand bijgewerkt.
